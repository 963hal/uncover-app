# UNCOVER アプリ（P5試作・PWA）

## 二つの見え方（データ共通）
- ワールド（index.html・標準）: 背後三人称の夜森遺跡。実道路は石畳、城・かがり火あり
- マップ（map.html・P4.3退避版）: 従来の高カメラ＋道路線＋開拓マス。ワールド内のマップボタンで移動

## 開き方

## 開き方
- PC: http://localhost:8001/ （Mac起動中に有効）
- Android: 公開URL（`docs/PUBLIC-URL.md`）をChromeで開く

## Androidにアプリとして入れる（インストール不要・無料）
1. AndroidのChromeで公開URLを開く
2. 右上メニュー（︙）→「ホーム画面に追加」→「インストール」
3. ホームのUNCOVERアイコンから全画面で起動（次回からURL不要・オフラインでも殻は開く）

## 遊び方
- 歩く（GPS:ONで現実・OFFでスティック）→近づくと自動でゲット（20m・ブッ＋音）
- 今日の目標は5匹＆10マス。達成でお祝い
- `モンスターずかん`で収集確認。減ると新しいモンスターが自動で現れる
- `モード:家`で同じ世界を再探索。仲間に`おやつ`でなつき度★（最大3）
- 1本指=回転・2本指上下=傾き・ピンチ=拡大縮小
- 右下の丸い地図がミニマップ（北上・自キャラ中心・金=未ゲット）
- 右上`UI非表示`で全UIを消して風景だけに（もう一度で復帰）
- `かんたん表示:ON`で試用ボタンを隠す

## 注意
- 公開URLはMac起動中のみ有効な使い捨て。安定公開（GitHub Pages等）はP2後半で用意
- データは端末内保存（localStorage）。機種変更で引き継がないP2仕様
